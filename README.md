# Escapa de Beyoncé

Juego sencillo de navegador hecho con HTML, CSS y JavaScript para practicar objetos, variables, arreglos y manejo de eventos.

🎮 **Jugar en línea:** https://al067599-max.github.io/Ejercicio-Escapa-de-Beyonce/

## Cómo se juega
- Mueve el cuadro azul con las flechas del teclado.
- El enemigo te persigue. Si te atrapa, aparece una alerta y el juego se reinicia.

## Panel de configuración
- Velocidad del jugador
- Velocidad del enemigo
- Color de fondo
- Música (activar y pausar)
- Volumen

## Archivos
- `index.html`: estructura del juego y panel de configuración
- `app.css`: estilos
- `app.js`: lógica del juego (movimiento, colisiones y configuración)
- `boss.png`: imagen del enemigo
